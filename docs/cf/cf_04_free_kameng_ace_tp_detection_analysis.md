## 五、下载过可疑“免费卡盟工具”？先排查，不要急着乱删系统文件

如果已经运行过来源不明的CF工具，第一原则不是下载另一个所谓“专杀工具”，而是先建立证据。

以下命令均用于**防御性排查**。

### 1. 查看系统驱动

管理员 PowerShell：

```powershell
Get-CimInstance Win32_SystemDriver |
Select-Object Name, State, StartMode, PathName |
Sort-Object Name
```

`Win32_SystemDriver` 是 Windows 官方提供的系统驱动信息接口，可查看驱动名称、状态、启动模式和路径。

重点关注：安装可疑软件后突然出现、路径异常、厂商未知的驱动。

**不要因为看不懂名字就直接删除驱动。**

### 2. 检查可疑文件数字签名

```powershell
Get-AuthenticodeSignature "C:\可疑文件路径\example.sys" |
Format-List Status, StatusMessage, SignerCertificate
```

PowerShell 官方的 `Get-AuthenticodeSignature` 可以检查文件 Authenticode 签名状态。

无签名不等于100%恶意，有签名也不意味着100%安全，但它是判断来源的重要证据之一。

### 3. 排查计划任务

CMD：

```cmd
schtasks /query /fo LIST /v
```

该命令可以详细列出本机计划任务及其执行程序。微软官方文档确认 `/query /v` 可用于查看详细任务信息。

重点检查那些指向 `%AppData%`、临时目录或陌生下载目录的异常任务。

如果经过确认某任务确属恶意，再针对**准确任务名称**删除：

```cmd
schtasks /delete /tn "\准确的任务名称" /f
```

不要使用通配符批量删除全部计划任务，否则可能破坏正常软件和系统组件。微软也明确指出，删除计划任务本身并不会自动删除任务所调用的恶意程序。

### 4. 启动 Defender 完整扫描

```powershell
Start-MpScan -ScanType FullScan
```

这是微软官方 Defender PowerShell 扫描接口。

如果怀疑存在 Rootkit、驱动级持久化或普通Windows环境中难以清除的恶意程序，可在保存工作后执行：

```powershell
Start-MpWDOScan
```

它会重启计算机并进入 Defender Offline 环境扫描；微软说明该模式尤其适合检查试图躲避正常Windows内核环境的 Rootkit 等持久化威胁。

如果账号已经出现异常登录，还应立即在另一台可信设备上修改相关密码、退出其他会话，并重新检查绑定邮箱与二次验证状态。
