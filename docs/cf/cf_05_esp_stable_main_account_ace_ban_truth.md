# 七、怀疑中过“内部驱动”？先别启动游戏，先检查电脑

如果你曾经下载过所谓 CF 透视、DMA 配套程序、驱动加载器、“过 ACE 登录器”或者要求关闭安全软件的压缩包，可以先进行基础排查。

以下命令用于**防御性检查**。

### 1. 查看当前系统驱动

PowerShell：

```powershell
Get-CimInstance Win32_SystemDriver |
Select-Object Name, State, StartMode, PathName |
Sort-Object Name
```

CMD：

```cmd
driverquery /v
```

重点关注安装外挂之后突然出现、路径异常、名称随机、位于临时目录或陌生文件夹中的驱动。

不要仅凭“名字奇怪”直接删除系统驱动。

---

### 2. 检查计划任务

PowerShell：

```powershell
Get-ScheduledTask |
Select-Object TaskName, TaskPath, State
```

CMD：

```cmd
schtasks /query /fo LIST /v
```

尤其检查那些在登录、开机或每隔几分钟触发，却指向 `%TEMP%`、`AppData` 或陌生目录的任务。

如果已经**确认**某个任务属于恶意程序，再删除：

```cmd
schtasks /Delete /TN "已确认的恶意任务名称" /F
```

不要把不认识的 Windows 系统任务一股脑删除。

---

### 3. 检查可疑程序数字签名

```powershell
Get-AuthenticodeSignature "C:\可疑文件路径\example.sys" |
Format-List
```

没有有效签名并不自动等于木马，但来自外挂压缩包、要求管理员权限、又缺乏可信签名的驱动，风险已经足够高。

如果曾允许对方远控电脑，还应立即修改重要账号密码、重新检查登录设备和二次验证状态，并使用可信安全软件进行全盘扫描。

严重感染或无法判断系统完整性时，**干净重装系统往往比继续猜测哪个文件是后门更可靠。**
